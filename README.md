# 李嘉琳 · 电商设计作品集

橘色渐变个人作品集，包含个人介绍、工作与教育经历、四个作品分类、个人优势及联系方式。

## 本地查看

下载仓库后，用浏览器打开 `index.html`，无需安装依赖。请保留网页文件与 `assets` 文件夹的相对位置。

## 网站文件

- `index.html`：网页内容与布局。
- `styles.css`：橘色渐变主题和电脑、手机排版。
- `app.js`：联系方式复制、微信二维码放大与滚动入场。
- `interactions.js`、`interactions.css`：导航滑动高亮、粒子动效、首屏入场、文字鼠标感应、头像倾斜追光、优势标签浮现，以及作品分类页面与浏览器前进后退。
- `assets/`：个人头像、完整简历、微信二维码和网站图标。

作品图片尚未补充，四个分类保留明确的“作品待补充”展示位。支持触屏、键盘操作及系统减少动态效果设置。

## GitHub Pages

需要公开网站时，可在仓库的 **Settings → Pages** 中选择 **Deploy from a branch**，选择 `main` 分支和 `/ (root)` 后保存。此仓库提交本身不代表已经开启网站发布。
